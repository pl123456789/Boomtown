Boomtown v0.5.2.3 — Auto Populate Generated Data

Automatically populates:
- Hope1858 in the World Generator window
- latest generated RiverData into ProspectingLocationSensor
- latest generated BoomtownGeologyData into GoldPanningController
- generated geology and terrain in the Gold Reveal window

Automatic assignment runs during world generation.

Manual fallback menu:
Boomtown > World Generator > Auto Populate Generated Data

Install:
Replace Assets/Boomtown/Scripts/WorldGeneration with the included folder.
Replace GoldPanningController.cs with the included gameplay file.
